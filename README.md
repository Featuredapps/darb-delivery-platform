# دَرْب | DARB

منصة توصيل متعددة الأدوار: عميل، بائع، سائق، وإدارة.

المصدر الكامل للمشروع موجود ضمن مجلدي `backend/` و`mobile/`.

## الحالة
هذه نسخة تطوير وليست إصدار إنتاج. لم يكتمل ربط مزود SMS سوري فعلي أو Firebase Cloud Messaging أو الخرائط والتتبع الحي. كما لم يكتمل بناء APK أو اختبار تشغيل متكامل. راجع ملفات README داخل كل جزء قبل التشغيل.

## Backend
NestJS + Prisma + PostgreSQL/PostGIS + Redis.

## Mobile
Flutter، واجهة عربية RTL.

## تنبيه
لا تضع أسرار الإنتاج في المستودع. استخدم ملفات البيئة المحلية وفعّل HTTPS وأوقف cleartext traffic قبل النشر.
